# اصلاح نام خیابان‌ها، کوچه‌ها و POI در نقشهٔ آفلاین آبتین مپس

## علت نمایش‌ندادن نام‌ها و POIها

فایل `IR.abm` قبلی فقط لایه‌های هندسی راه، زمین، آب و ساختمان را در PMTiles داشت. لایهٔ vector جداگانه‌ای برای برچسب خیابان یا POI تولید نشده بود. علاوه بر آن، style داخلی `day.json` و `night.json` هیچ `glyphs`، `sprite` یا `symbol layer` برای متن و آیکون نداشت. بنابراین خطوط راه دیده می‌شدند، اما هیچ نام یا POI قابل رسم نبود.

## این patch چه می‌کند

| بخش | تغییر |
|---|---|
| `roads` در PMTiles | `name` و `name:fa` را از OSM نگه می‌دارد و نام جاده‌های اصلی را از zoom 9 و نام راه‌های محلی/کوچه‌ها را از zoom 14 نمایش می‌دهد. |
| `pois` در PMTiles | POIهای دارای نام را به‌صورت point یا point-on-surface برای areaها تولید می‌کند؛ شامل سوخت، پارکینگ، درمان، داروخانه، پلیس، مدرسه، رستوران، بانک، هتل، فروشگاه، مسجد، حمل‌ونقل، گردشگری، پارک و دوربین سرعت. |
| style روز/شب | symbol layerهای نام خیابان و POI، glyph فارسی `Vazirmatn` و sprite آیکون را فعال می‌کند. عرض راه‌ها در zoom پایین نیز کمتر شده تا نقشه خلوت‌تر باشد. |
| همان `IR.abm` واحد | graph مسیریابی اکنون POIهای OSM را هم در section داخلی خود دارد؛ ایندکس جست‌وجوی آفلاینِ فعلی اپ همان POIها را از همان فایل `.abm` می‌خواند. فایل نقشه، دیتابیس یا دانلود دوم ساخته نمی‌شود. |
| اعتبارسنجی | builder اکنون اگر style، glyph یا sprite لازم داخل ABM نباشد، map را نامعتبر اعلام می‌کند. |

## نحوهٔ استفاده

فقط محتویات این patch را در **root همان repository** استخراج و فایل‌های هم‌نام را جایگزین کنید. سپس workflow ساخت نقشه را برای کشور `IR` اجرا کنید. خروجی قبلی `IR.abm` به‌طور خودکار نام و POI دریافت نمی‌کند؛ باید یک‌بار با این schema دوباره ساخته و در release منتشر شود.

پس از نصب نسخهٔ تازهٔ `IR.abm` در اپ، نقشهٔ آفلاین را انتخاب کنید. نام راه‌های اصلی از zoom حدود 9، POIهای مهم از حدود 11 تا 12، و کوچه‌ها/راه‌های محلی از zoom 14 به بعد دیده می‌شوند. فاصلهٔ zoom برای جلوگیری از شلوغی و سنگین‌شدن نقشه است.

## جست‌وجوی آفلاین

جست‌وجو برای نام خیابان و نام POI به دادهٔ نام نیاز دارد. این patch نام راه‌ها و POIها را در همان ABM ذخیره می‌کند. POIهای بدون نام در OSM برای search دسته‌ای قابل نگهداری هستند، اما برای جلوگیری از شلوغی، روی نقشه تنها POIهای نام‌دار آیکون و برچسب می‌گیرند. کیفیت و کامل‌بودن نام‌ها به برچسب‌های موجود در OpenStreetMap برای هر منطقه وابسته است.

## کنترل‌های انجام‌شده

- syntax shell، Python، JSON و YAML کنترل شده است.
- تست باینری graph تأیید کرده است که POI نام‌دار همراه کلاس و zoom در ABM نوشته می‌شود.
- یک container تک‌فایلی واقعی با PMTiles معتبر، graph، دو style، تمام glyphهای فارسی و تمام spriteها ساخته و با verifier Python و Dart تأیید شده است.
- تست‌های مرتبط Flutter پاس شده‌اند و تحلیل کامل Flutter بدون error اجرا شده است.
- در این محیط Docker موجود نبود؛ بنابراین ساخت کامل ایران در همین محیط اجرا نشد. پس از اجرای workflow، خروجی `IR.abm` جدید باید توسط verifier خود workflow تأیید شود.

## نکتهٔ عملکرد مسیریابی

کندی routing مربوط به data/style این patch نیست. علت‌های کدی که جداگانه دیده شدند شامل decode اولیهٔ graph، snap کردن با پیمایش یال‌های کاشی‌های بارگذاری‌شده، و ساخت متوالی تا سه مسیر جایگزین روی isolate اصلی هستند. این مورد باید در مرحلهٔ جداگانه با profiling و بدون مخلوط‌کردن با اصلاح label/POI بهینه شود.
