# سازندهٔ نقشهٔ تک‌فایلی ABTINMAP

برای هر بستهٔ قابل دانلود فقط یک فایل `XX.abm` ساخته و منتشر می‌شود؛ برای نمونه `IR.abm` یا `TR.abm`. کشورهایی که منبع دادهٔ بسیار بزرگی دارند، به بسته‌های ناحیه‌ای مستقل تقسیم می‌شوند؛ مانند `US-NE.abm`، `US-WE.abm` و `RU-SIB.abm`. همهٔ این بسته‌ها در اپ زیر نام و پرچم همان کشور مادر نمایش داده می‌شوند.

این فایل واحد شامل سه بخش است: گراف مسیریابی، شاخص جستجوی آفلاین و اطلس تصویری چندزومیِ ازپیش‌رندرشدهٔ سرور. اطلس آماده و تصویر overview کوچک به انتهای ABM افزوده می‌شوند و با footer هفتادودوبایتی `ABTATLS2` پیدا می‌شوند. اپ همان ABM را یک‌بار دانلود می‌کند، ابتدا overview را برای نمایش فوری نشان می‌دهد، سپس اطلس را محلی استخراج می‌کند و فقط تصویرهای WebP آماده را نمایش می‌دهد.

برای به‌روزرسانی، workflow علاوه بر ABM کامل، یک patch باینریِ بلوکی می‌سازد. هنگامی که هش نسخهٔ نصب‌شده با `base_sha256` patch منطبق باشد، اپ فقط بلوک‌های تغییرکرده را دریافت و در یک فایل موقت بازسازی می‌کند. هش نهایی قبل از جایگزینی اتمیک بررسی می‌شود؛ در نتیجه نسخهٔ فعلی در زمان قطع اینترنت یا patch نامعتبر سالم می‌ماند. اگر patch مناسب برای نسخهٔ نصب‌شده وجود نداشته باشد، اپ به دریافت کامل ABM برمی‌گردد.

Workflow همه کشورها را با ورودی پیش‌فرض `all` می‌سازد و تا شش منطقهٔ مستقل را هم‌زمان اجرا می‌کند. رندر هر منطقه دادهٔ PBF را فقط یک‌بار می‌خواند، PNGهای موقت را با فشرده‌سازی سبک می‌نویسد و تبدیل WebP را در دو پردازش انجام می‌دهد. سقف پیش‌فرض زوم ۱۲ است تا ساخت کشورها به رندر زوم ۱۳ که اغلب به‌علت سقف حجم نهایی حذف می‌شد، زمان بیهوده اختصاص ندهد. برای ایران، اطلس با سقف هدف ۲۶۰ مگابایت تولید می‌شود؛ اگر جزئیات زوم‌های بالا از سقف عبور کنند، سازنده زوم بالاتر را حذف می‌کند. حجم نهایی `IR.abm` برابر بخش جستجو/مسیر به‌علاوه اطلس تصویر آماده است.

# بخش اطلس رندرشده در ABM

پسوند فایل نهایی برای هر کشور همان `.abm` باقی می‌ماند. پس از داده‌های معمول ABTINMAP، سازنده SQLite اطلس رندرشده را به فایل اضافه می‌کند و یک footer ۵۶ بایتی با magic `ABTATLS1` می‌نویسد.

| بخش داخل ABM | مصرف در اپ |
|---|---|
| هدر، گراف و شاخص ABTINMAP | مسیریابی و جستجوی آفلاین |
| SQLite اطلس WebP | نمایش نقشهٔ آماده، ساختمان ساده و POI |
| footer اطلس | یافتن و استخراج امن SQLite بدون فایل دانلودی دوم |

اپ هیچ‌وقت فایل اطلس جداگانه دانلود نمی‌کند. با انتخاب یک کشور، فقط `XX.abm` دریافت می‌شود.
