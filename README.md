# سازندهٔ نقشهٔ تک‌فایلی ABTINMAP

برای هر کشور فقط یک فایل `XX.abm` ساخته و منتشر می‌شود؛ برای نمونه `IR.abm` یا `TR.abm`.

این فایل واحد شامل سه بخش است: گراف مسیریابی، شاخص جستجوی آفلاین و اطلس تصویری چندزومیِ ازپیش‌رندرشدهٔ سرور. اطلس آماده و تصویر overview کوچک به انتهای ABM افزوده می‌شوند و با footer هفتادودوبایتی `ABTATLS2` پیدا می‌شوند. اپ همان ABM را یک‌بار دانلود می‌کند، ابتدا overview را برای نمایش فوری نشان می‌دهد، سپس اطلس را محلی استخراج می‌کند و فقط تصویرهای WebP آماده را نمایش می‌دهد.

برای به‌روزرسانی، workflow علاوه بر ABM کامل، یک patch باینریِ بلوکی می‌سازد. هنگامی که هش نسخهٔ نصب‌شده با `base_sha256` patch منطبق باشد، اپ فقط بلوک‌های تغییرکرده را دریافت و در یک فایل موقت بازسازی می‌کند. هش نهایی قبل از جایگزینی اتمیک بررسی می‌شود؛ در نتیجه نسخهٔ فعلی در زمان قطع اینترنت یا patch نامعتبر سالم می‌ماند. اگر patch مناسب برای نسخهٔ نصب‌شده وجود نداشته باشد، اپ به دریافت کامل ABM برمی‌گردد.

Workflow همه کشورها را با ورودی پیش‌فرض `all` می‌سازد. برای ایران، اطلس با سقف هدف ۲۶۰ مگابایت تولید می‌شود؛ اگر جزئیات زوم‌های بالا از سقف عبور کنند، سازنده زوم بالاتر را حذف می‌کند. حجم نهایی `IR.abm` برابر بخش جستجو/مسیر به‌علاوه اطلس تصویر آماده است.
